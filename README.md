# API Testing Demo

Lightweight TypeScript HTTP client built with Axios and Bun. Demonstrates a singleton `ApiClient` wrapper and a typed `UserService` for fetching, finding, creating, updating and deleting users against the JSONPlaceholder API.

## Getting Started

Install dependencies:

```bash
bun install
```

Run the example script:

```bash
bun dev # has the --watch flag
# or
bun start
```
